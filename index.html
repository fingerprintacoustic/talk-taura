Word building

How Shona words are built

Most Shona words are a small prefix joined to a root. The prefix tells you the noun class — is it a person, a thing, a place, a big version, a small version?

zi- and svi- sit on the same root but pull it in opposite directions: zikomana is a big boy, svikomana is a tiny or skinny boy — a size contrast, not a singular/plural pair.

Making it yours — possessive endings

Endings like -angu (mine), -ako (yours), and -edu (ours) attach to a concord that matches the noun's class — that's why the ending changes shape depending on the word.

How to choose the right form: look at how the noun itself starts.
• mu- class nouns (mostly people) like mwana, murume, mukomana → use w- (mwana wangu)
• chi- class nouns (mostly things) like chingwa, chinhu → use ch- (chingwa changu)
• borrowed nouns like bhuku → use r- (bhuku rangu)
• class 9/10 nouns like imbwa or nyika → use y- for one, dz- for more than one (imbwa yangu = my dog, imbwa dzangu = my dogs) — the noun itself doesn't change, the ending does the counting.

Singular & plural — which words change

Some noun classes change shape for "more than one." Others — mostly class 9/10, and many borrowed words — stay exactly the same; you can only tell the number from the rest of the sentence, the same way imbwa yangu vs. imbwa dzangu worked above.

Respect & register

Shona has a built-in way to show respect: swap the informal "u-" for "mu-"/"ma-" when speaking to an elder, a stranger, or someone you want to honor — the same shift you'd make between "you" (casual) and a more formal address.

Informal / casualRespectful / elderMeaning
If someone greets you casually with Wakadii?, a natural informal reply is Ndiri bho — "I'm good." It's more relaxed than Ndiripo, the same way "I'm good" is more casual than "I am well."
